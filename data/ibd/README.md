# IBD: BIO2 kritieke processen gemeenten

The Informatiebeveiligingsdienst (IBD) publishes a list of critical processes for municipalities under BIO2. Use it on axis 1 of the classification model to decide whether a system supports a business-critical process.

- Product page: <https://www.informatiebeveiligingsdienst.nl/product/bio2-kritieke-processen-gemeenten/>

**Status:** being prepared. We are checking whether the list may be redistributed in this repository. Until then, use the product page.
