# Inkoopcasussen

Hier komen de casussen waarop je je tool demonstreert. Verwacht:

- een geanonimiseerde casus van een GGD;
- een of twee casussen uit TenderNed.

Elke casus beschrijft het systeem of de dienst, de gegevens die erin zitten, hoe kritiek het proces is, de huidige situatie en waar mogelijk een fragment uit het bestek of programma van eisen.

Status: in voorbereiding.
